Drop ONE image in this folder and it becomes the hero illustration automatically —
no code change. Leave the folder empty and the hero renders as pure typography.

- Square-ish (1:1) works best; the slot is up to 30rem wide on desktop.
- PNG with transparency, or WebP/JPEG on a dark ground.
- Aim for under ~400 KB. Run `npm run images` after adding it if it is large.
- The first file wins if there is more than one.
